Schematic

As an employee at the toy company, I propose a "control traffic" game. This games includes pressing a black button that colors the colors green, yellow and red. At each push the color changes from Green to yellow to Red. Once the button is pressed the color is faded to brightness this is also meant to be a timer for the cars

Circuit

I have 3 LEDs, green, yellow and red. Each represent a traffic light there is a resistor on each of them of 220V, each color also connects to ~9, ~10, ~11. I used these pins becuase they support PWM, which let's us control how bright each color is. GND is connected to the 0V supply, green, yellow and red are connect to GND through that supply.

Each LED draws 20 mA, which is within the commonly recommended operating current per Arduino Uno I/O pin.

The four LEDs draw 80 mA combined, which is below the ATmega328P's 200 mA absolute maximum for the microcontroller's supply pins.

The Arduino itself also consumes current, so its total draw will be higher than 80 mA.
