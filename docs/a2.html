01 · DESIGN

Project Schematic

As an employee at a toy company, I propose a "control traffic" game. This game includes pressing a black button that changes the colors green, yellow, and red. At each push, the color changes from green to yellow to red. Once the button is pressed, the color fades in brightness. This is also meant to act as a timer for the cars.

02 · HARDWARE

Circuit

I have 3 LEDs: green, yellow, and red. Each represents a traffic light. There is a 220-ohm resistor on each of them. Each color also connects to pins ~9, ~10, and ~11. I used these pins because they support PWM, which allows us to control how bright each color is.

GND is connected to the 0V supply. The green, yellow, and red LEDs connect to GND through that supply.
